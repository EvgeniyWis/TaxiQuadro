# Такси и отдых — Сиверский

Лендинг по макету Figma (Desktop 1440 / Mobile 390) + бэкенд: заявки уходят в Telegram, ассистент Eva отвечает через ChatGPT.
Зависимостей нет — нужен только Node.js 18.17+.

```
index.html, style.css, script.js, img/   — сайт
server/                                  — Node-сервер (статика + API + Telegram-бот)
  index.js      маршруты /api/lead, /api/eva, /api/health, раздача сайта
  telegram.js   отправка заявок, кнопка «Взять в работу», /start и /id
  eva.js        промпт Eva, вызов OpenAI, функции create_lead / show_section
  test/         автотесты (npm test)
```

## Запуск

```bash
cp .env.example .env     # заполнить значения
npm start                # http://localhost:3000
npm test                 # 11 тестов с моками Telegram и OpenAI
```

Без ключей сайт работает: заявки в dev-режиме печатаются в консоль, Eva отвечает заготовленными фразами.
В `NODE_ENV=production` без настроенного Telegram форма вернёт пользователю ошибку, а не «успех».

## Обычный PHP-хостинг (pro100ibusiness.ru)

Сайт выложен на виртуальный хостинг без Node.js, поэтому вместо `server/` работает `api/lead.php`
(`.htaccess` отдаёт его по адресу `POST /api/lead`, фронтенд менять не нужно). В папку сайта (`www/pro100ibusiness.ru/`) по FTP кладутся
`index.html`, `style.css`, `script.js`, `img/`, `api/lead.php`, `.htaccess`.

Настройки заявок — файл `lead-config.php` в домашней папке хостинга, **рядом с `www/`, вне сайта** (шаблон: `api/lead-config.example.php`, в git не попадает):

- `mail_to` — почта для заявок (сейчас Pro100iBusines@gmail.com; письма с хостинга могут попадать в «Спам»);
- `telegram_token` и `telegram_chat_ids` — чтобы заявки шли ещё и в Telegram. Кнопки «Взять в работу» в этом варианте нет: она требует постоянно работающего бота (`server/`).

## Telegram-бот для заявок (Node-сервер)

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен в `TELEGRAM_BOT_TOKEN`.
2. Запустите сервер, напишите боту `/start` — он пришлёт **chat id**. Для группы: добавьте бота в группу и отправьте `/id`.
3. Впишите id в `TELEGRAM_CHAT_IDS` (несколько — через запятую) и перезапустите сервер.

Каждая заявка (водитель, бронь, заявка из чата Eva) приходит сообщением с кнопкой **«✅ Взять в работу»**:
нажатие закрепляет заявку за менеджером (его @username появляется на кнопке). Кнопки работают только в чатах из `TELEGRAM_CHAT_IDS`.
Бот работает через long polling — домен и HTTPS для него не нужны.

## Eva (виджет eva.bz)

На сайте работает готовый виджет ассистента: `<script src="https://eva.bz/widget/chat-widget.js?widgetId=…">` в конце `index.html`
(ID выдаёт кабинет eva.bz; база знаний, внешний вид и заявки настраиваются там). Домен `eva.bz` разрешён в CSP сервера (`EVA_HOSTS` в `server/index.js`).

Ниже — прежний самописный чат на ChatGPT. С сайта он убран, но серверная часть (`/api/eva`) осталась и сейчас никем не используется.

### Самописная Eva (ChatGPT, не подключена)

Ключ — в `OPENAI_API_KEY`, модель — `OPENAI_MODEL` (по умолчанию `gpt-4o-mini`).
Eva знает услуги, цены и контакты из макета (см. `SYSTEM_PROMPT` в `server/eva.js` — там же править базу знаний),
не выдумывает неизвестное («уточняется» → предлагает позвонить) и умеет два действия:

- `create_lead` — когда клиент назвал имя и телефон, заявка уходит в Telegram;
- `show_section` — в чате появляется кнопка «→ Квадро-маршруты» и т.п., которая прокручивает страницу к разделу.

Фразы-заглушки на случай недоступного ChatGPT жили в `script.js`; из фронтенда они удалены вместе с чатом.

## Безопасность

- ключи только в `.env` (в `.gitignore`), сервер отдаёт лишь `index.html`, `style.css`, `script.js` и `img/*`;
- лимиты по IP: 6 заявок и 30 сообщений Eva за 10 минут; тело запроса ≤ 16 КБ; honeypot-поле от ботов;
- весь пользовательский ввод проходит валидацию и экранируется перед отправкой в Telegram;
- сообщения клиента в ChatGPT идут только как `user`/`assistant` (роль `system` от клиента отбрасывается);
- CSP запрещает сторонние скрипты. За nginx/Cloudflare включите `TRUST_PROXY=1`, иначе лимиты считаются по IP прокси.

## Что осталось заполнить

- ссылка онлайн-оплаты: `<meta name="pay-url" content="…">` в `index.html` (пока кнопка «Оплатить по ссылке» скрыта);
- ссылки на сторы (RuStore / App Store / Google Play) и «Яндекс Карты» — сейчас заглушки;
- тексты, помеченные в макете как «уточняется» (цены велосипедов, VIP, экспедиция, политика обработки данных).
